# 🔥 DebugForge

**Fix errors faster. Understand bugs better. Save solutions that actually help.**

DebugForge is a frontend developer tool designed to help you:
- Decode JavaScript errors
- Search common programming issues
- Learn why errors happen
- Save debugging solutions
- Speed up your development workflow

It works fully in the browser using **Vanilla JavaScript + LocalStorage** (no backend required).

---

## 🚀 Live Features

### 🐛 Error Decoder
Paste any error message and get:
- Meaning of the error
- Common causes
- Practical solutions

---

### 📚 Error Library
Search a built-in database of common errors:
- JavaScript errors
- Network errors (404, 500)
- API errors (CORS, fetch)
- Node.js errors

---
